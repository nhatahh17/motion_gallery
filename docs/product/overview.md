# Product Overview

## Product

Personal Experimental Motion Gallery is a single-page personal photography
gallery. The experience should feel calm, minimal, and motion-led rather than
like a conventional portfolio grid.

## Primary Contract

- The site opens to a white/off-white full-screen gallery.
- The default layout is `2D Circle`.
- The gallery eventually supports 30+ mixed-ratio photos from local JSON data.
- Users can drag/swipe, switch layouts, and open an image detail view.
- The design should keep UI chrome quiet so photos and motion carry the page.

## MVP Scope

- Next.js + TypeScript foundation.
- Local JSON data model.
- React Three Fiber image planes.
- Three layout modes: `circle2d`, `circle3d`, `horizon3d`.
- Autoplay, drag, inertia, modal metadata, responsive tuning, reduced motion.

## Non-Goals

- CMS, login, upload, ecommerce, comments, audio, blog, or complex filters for
  the first MVP.
